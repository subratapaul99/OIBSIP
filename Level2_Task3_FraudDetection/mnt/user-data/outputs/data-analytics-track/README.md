# Data Analytics Track

My projects for the Data Analytics track, built with Python, pandas, scikit-learn, matplotlib and seaborn.

| # | Project | What it shows |
|---|---|---|
| 01 | [EDA on Retail Sales](01-retail-sales-eda) | Exploratory analysis, trends, customer and product insights |
| 02 | [Data Cleaning](02-data-cleaning) | Missing values, duplicates, outliers, standardisation |
| 03 | [Customer Segmentation](03-customer-segmentation) | RFM analysis and K-Means clustering |
| 04 | [House Price Prediction](04-house-price-prediction) | Linear regression, evaluation and interpretation |
| 05 | [Wine Quality Prediction](05-wine-quality-prediction) | Multi-model classification and imbalanced classes |
| 06 | [Fraud Detection](06-fraud-detection) | Imbalanced data, SMOTE, precision/recall and AUC-ROC |

## How to run
1. `pip install pandas numpy matplotlib seaborn scikit-learn imbalanced-learn jupyter`
2. Open any notebook in Jupyter or VS Code and run all cells.

Each project folder has its own README with the problem, dataset, key findings and results.
