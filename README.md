# OIBSIP - Data Analytics Internship

**By Subrata Paul**

This repository contains my projects for the Data Analytics track of the Oasis Infobyte Internship Program (OIBSIP). Each project has its own folder with a Jupyter notebook, the dataset (or a link to it) and a README that explains the problem, the approach and the key findings.

## Tools used
Python, pandas, numpy, matplotlib, seaborn, scikit-learn, imbalanced-learn, NLTK, pyspellchecker, plotly, Jupyter Notebook

## How to run
1. Clone the repo: `git clone https://github.com/subratapaul99/OIBSIP.git`
2. Install the libraries:
   `pip install pandas numpy matplotlib seaborn scikit-learn imbalanced-learn nltk wordcloud plotly pyspellchecker jupyter`
3. Open any notebook in Jupyter or VS Code and run all cells.

## Notes
- Datasets come from Kaggle or UCI. Large files are linked in each project's README instead of being uploaded.
- File naming format: `SubrataPaul_L1T1.ipynb` (Level 1, Task 1), and so on.
